# Storage

File storage for Pola with pluggable drivers, inspired by Rails Active Storage.

## Overview

The `storage` package provides a `Storage` interface for saving, reading, listing, and deleting files. Two built-in drivers are included:

- **`fs`** — Local filesystem storage
- **`rclone`** — Cloud storage via [rclone](https://rclone.org) (S3, GCS, Azure, and 70+ providers)

File metadata is persisted via `StorageBlob` and `StorageAttachment` ORM models, generated by the CLI. Models can reference blobs directly (foreign key) or polymorphically (via attachments).

## Quick Start

```bash
# Generate storage models and configure Polafile
pola generate storage

# Or with a specific driver
pola generate storage --driver s3 --bucket my-uploads
pola generate storage --driver fs --root ./uploads
```

This does two things:

1. Adds a `storage` block to `Polafile.hcl`
2. Generates `StorageBlob` and `StorageAttachment` models using your configured ORM

## Associating Files with Models

### Direct Relationship

A model has a direct foreign key to `StorageBlob`:

```bash
pola generate model User name:string email:string avatar:references
```

This creates a `User` model with an `AvatarID` field referencing `StorageBlob`.

### Polymorphic Relationship

The generated `StorageAttachment` model uses polymorphic references (`record:references{polymorphic}`), allowing any model to have file attachments without additional foreign keys:

```
StorageAttachment:
  name        — attachment name (e.g. "avatar", "documents")
  record_type — polymorphic type (e.g. "User", "Product")
  record_id   — polymorphic ID
  blob_id     — FK to StorageBlob
```

## Storage Interface

```go
type Storage interface {
    Save(ctx context.Context, content io.Reader, path string) error
    Stat(ctx context.Context, path string) (*Stat, error)
    Open(ctx context.Context, path string) (io.ReadCloser, error)
    Delete(ctx context.Context, path string) error
    List(ctx context.Context, path string) ([]*Stat, error)
}
```

## Drivers

### Filesystem

```go
import "github.com/polagonow/pola/storage/fs"

store := fs.NewStorage(fs.Config{
    Root: "./uploads",
})
```

### Rclone (S3 / Cloud)

```go
import "github.com/polagonow/pola/storage/rclone"

// S3 backend
store := rclone.NewStorage("s3", "my-bucket")

// Local filesystem via rclone
store := rclone.NewStorage("local", "/tmp/uploads")
```

To add more rclone backends, import them:

```go
import (
    _ "github.com/rclone/rclone/backend/googlecloudstorage"
    _ "github.com/rclone/rclone/backend/azureblob"
    // or import all:
    // _ "github.com/rclone/rclone/backend/all"
)
```

## Plugin

Register the storage service in Pola's DI container:

```go
import (
    "github.com/polagonow/pola/storage"
    "github.com/polagonow/pola/storage/fs"
)

store := fs.NewStorage(fs.Config{Root: "./uploads"})

app := pola.New(
    storage.Plugin(store),
    // ... other plugins
)
```

Then resolve it in route handlers:

```go
func (r *Route) Init(registry *core.Registry) error {
    r.storage = core.MustInvoke[storage.Storage](registry)
    return nil
}
```

## Polafile Configuration

```hcl
pola {
  storage {
    driver = "fs"
    root   = "./uploads"
  }
}
```

With S3:

```hcl
pola {
  storage {
    driver = "s3"
    remote = "s3"
    bucket = "my-app-uploads"
  }
}
```

Per-environment overrides:

```hcl
pola {
  storage {
    driver = "fs"
    root   = "./uploads"

    env "production" {
      driver = "s3"
      remote = "s3"
      bucket = "prod-uploads"
    }
  }
}
```

## Generated Models

Running `pola generate storage` creates two models:

### StorageBlob

| Field        | Type   | Description                     |
|--------------|--------|---------------------------------|
| key          | string | Unique storage key (indexed)    |
| filename     | string | Original filename               |
| content_type | string | MIME type                       |
| byte_size    | int64  | File size in bytes              |
| checksum     | string | File checksum                   |

### StorageAttachment

| Field       | Type                    | Description                  |
|-------------|-------------------------|------------------------------|
| name        | string                  | Attachment name (indexed)    |
| record      | references{polymorphic} | Polymorphic owner reference  |
| blob        | references              | FK to StorageBlob            |

## Usage Example

```go
package main

import (
    "context"
    "strings"

    "github.com/polagonow/pola/storage"
    "github.com/polagonow/pola/storage/fs"
)

func main() {
    store := fs.NewStorage(fs.Config{Root: "./uploads"})

    ctx := context.Background()

    // Save a file
    content := strings.NewReader("hello world")
    err := store.Save(ctx, content, "greetings/hello.txt")

    // Read it back
    rc, err := store.Open(ctx, "greetings/hello.txt")
    defer rc.Close()

    // Get metadata
    stat, err := store.Stat(ctx, "greetings/hello.txt")

    // List files
    files, err := store.List(ctx, "greetings")

    // Delete
    err = store.Delete(ctx, "greetings/hello.txt")
}
```
