# injection

Go → JS runtime dependency injection for the Pola framework.

The `injection/do` package bridges Go services registered in a `samber/do` injector
into the JS runtime as `__DEPENDENCY_INJECTION__` async functions. Server components
call Go code (DB queries, services) through this bridge.

## Usage

```go
import (
    samberdo "github.com/samber/do/v2"
    doinjection "github.com/polagonow/pola/injection/do"
)

injector := doinjection.New(samberdo.New())

// Register Go services in the do injector
do.Provide(injector.Injector(), func(i *do.Injector) (*PostRepository, error) {
    return NewPostRepository(do.MustInvoke[*sql.DB](i)), nil
})

// Wire into Pola
app, _ := pola.New(&core.Config{
    Registry: &core.Registry{
        Injectors: []core.RuntimeInjector{injector},
    },
})
```

In a React server component:

```tsx
import di from '@pola/di'

export default async function PostsPage() {
    const posts = await di.getPosts()   // → PostRepository.GetPosts()
    return <PostList posts={posts} />
}
```

## `@pola/di` frontend package

Located at `ui/packages/di/`. Provides a typed `di` object that wraps
`__DEPENDENCY_INJECTION__`. Types are auto-generated by the build pipeline.

```ts
import di from '@pola/di'
const posts = await di.getPosts()
```
