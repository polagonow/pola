# Data Layer

Pola separates persistence into three layers, all generated by the CLI and wired
through a dependency-injection registry.

## Models

A **model** is an ORM-neutral struct — one canonical entity definition in
`db/models/`. Generate one from field specs:

```bash
pola generate model User name:string email:string:uniq age:int?
```

Field syntax is `field:type{options}:modifier`:

| Part | Examples |
|------|----------|
| type | `string`, `int`, `int64`, `float`, `bool`, `time`, `uuid`, `text`, `bytes`, `json`, `references` |
| validated string | `email`, `url`, `ip`, `alpha`, `numeric`, `semver`, … |
| options `{…}` | size `{255}`, `references{polymorphic}`, `references{StorageBlob}` |
| nullability | `?` optional · `!` required |
| modifiers | `index`, `uniq`, `hidden`, `required` |

## Repositories

A **repository** is a generic CRUD interface with an ORM-specific implementation.
The interface keeps your services ORM-agnostic:

```bash
pola generate repository User name:string email:string:uniq
```

```go
type UserRepository interface {
    Get(ctx context.Context, id uint) (*models.User, error)
    All(ctx context.Context) ([]models.User, error)
    Create(ctx context.Context, u *models.User) (*models.User, error)
    // Update, Delete, ...
}
```

## Services

A **service** holds business logic and depends on repositories:

```bash
pola generate service User name:string email:string
```

## Dependency injection

Repositories, services, routes, and actions are resolved from a **registry**
(`core.Registry`, built on `samber/do`). Constructors named `New*` that take
`*core.Registry` are auto-discovered and wired:

```go
func NewUserService(r *core.Registry) *UserService {
    return &UserService{users: core.MustInvoke[repositories.UserRepository](r)}
}
```

- `core.Provide[T](r, ctor)` / `core.ProvideValue[T](r, v)` — register.
- `core.Invoke[T](r)` / `core.MustInvoke[T](r)` — resolve by type.

> [!TIP]
> `pola generate scaffold User …` creates the model, repository, service, action,
> route, Zod schema, and CRUD pages together — all pre-wired.
